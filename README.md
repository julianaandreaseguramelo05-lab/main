## 🧪 Laboratorios y proyectos

### 🔎 Laboratorio 01 · Búsqueda de productos

Implementación de algoritmos para resolver un problema relacionado con la búsqueda de productos en una tienda.

Se aplican conceptos de programación, diseño de algoritmos y resolución de problemas.

---

### 🏪 Sistema de gestión de una tienda

Implementación de diferentes estructuras de datos para administrar las operaciones de una tienda:

- 👥 **Cola de clientes — FIFO**
- 📚 **Pila de atenciones — LIFO**
- 📦 **Lista doblemente enlazada — Catálogo de productos**
- 🔍 Búsqueda de productos.
- 🗑️ Eliminación de nodos.
- 🔄 Recorridos en ambas direcciones.
- ↩️ Función de deshacer mediante la pila.

---

### 🌳 Árboles Binarios · BST y AVL

Implementación y análisis de dos estructuras de árboles:

- 🌱 **Árbol Binario de Búsqueda — BST**
- ⚖️ **Árbol AVL**

Incluye:

- Inserción mediante recursividad.
- Cálculo del factor de balance.
- Rotaciones **LL, RR, LR y RL**.
- Recorrido **Preorden**.
- Recorrido **Inorden**.
- Recorrido **Postorden**.
- Visualización gráfica.
- Comparación entre BST y AVL.

---

## 📊 Análisis de complejidad

Durante el desarrollo de las actividades se analiza el comportamiento de los algoritmos mediante:

**T(n)** · **Mejor caso** · **Peor caso** · **Big-O**

El análisis permite comprender cómo cambia el tiempo de ejecución de una solución a medida que aumenta la cantidad de datos.
