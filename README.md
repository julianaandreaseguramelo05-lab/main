## 🧪 Laboratorios y proyectos

### 🔎 Laboratorio 01 · Búsqueda de productos

Desarrollo de una solución para un problema relacionado con la búsqueda de productos en una tienda, aplicando conceptos de programación y diseño de algoritmos.

### 🏪 Sistema de Gestión de una Tienda

Implementación de diferentes estructuras de datos para administrar las operaciones de una tienda.

**Estructuras utilizadas:**

- 👥 Cola de clientes — FIFO
- 📚 Pila de atenciones — LIFO
- 📦 Lista doblemente enlazada — Catálogo de productos

Se trabajan operaciones de inserción, eliminación, búsqueda, recorridos y una función de deshacer mediante la pila.

### 🌳 Árboles Binarios · BST y AVL

Implementación de dos estructuras de árboles:

**🌱 Árbol Binario de Búsqueda — BST**

**⚖️ Árbol AVL**

El proyecto incluye:

- Inserción mediante recursividad
- Factor de balance
- Rotaciones LL
- Rotaciones RR
- Rotaciones LR
- Rotaciones RL
- Recorrido Preorden
- Recorrido Inorden
- Recorrido Postorden
- Visualización de los árboles
- Comparación entre BST y AVL
